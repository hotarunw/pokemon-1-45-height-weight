# pokemon-1-45-height-weight

[![Static Badge](https://img.shields.io/badge/github-repo-blue?logo=github)](https://github.com/hotarunw/pokemon-1-45-height-weight)
[![Static Badge](https://img.shields.io/badge/GreasyFork-install-orange?logo=greasyfork)](https://greasyfork.org/ja/scripts/480725-pokemon-1-45-height-weight)

ポケモン徹底攻略の図鑑のページの高さと重さに、標準の1.45倍の値を表示する。

表示する理由は、GOの高さと重さが標準の1.45倍以上の場合、SVでサイズ最大（でっかい証）になると言われているから。
[XのGO 証 "1\.45"の検索結果](https://x.com/search?q=GO%20%E8%A8%BC%20%221.45%22&src=typed_query&f=live)
